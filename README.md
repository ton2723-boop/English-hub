# English Hub

เว็บเรียนภาษาอังกฤษตามกรอบมาตรฐานสากล **CEFR (A1–C2)** สำหรับผู้ใหญ่/คนทำงาน พร้อม **ทดสอบวัดระดับก่อนและหลังเรียน** และส่วน **เตรียมสอบ IELTS / TOEIC** หน้าเว็บสลับภาษาไทย/อังกฤษได้

## ฟีเจอร์

- **ทดสอบก่อนเรียน (pre-test) / หลังเรียน (post-test)** — คลังข้อสอบระดับละ 18 ข้อ (A1–C2 รวม 108 ข้อ) แต่ละครั้งสุ่มระดับละ 6 ข้อ (ไวยากรณ์/คำศัพท์ 4, การอ่าน 1, การฟัง 1) ข้อสอบหลังเรียนจะไม่ซ้ำกับข้อที่เคยทำ และจะหยุดเองเมื่อถึงระดับที่ยากเกินไป
  - ผ่านระดับเมื่อถูก ≥ 4/6 ข้อ และต้องผ่านทุกระดับก่อนหน้า (`src/lib/scoring.ts`)
  - **ข้อสอบหลังเรียนล็อกไว้** จนกว่าจะทำแบบฝึกหัดได้ ≥ 60% ในทุกบทของระดับที่แนะนำให้เรียน (`postTestGate` ใน `src/lib/level.ts`)
  - ข้อฟังใช้ Web Speech API ของเบราว์เซอร์ (ไม่ต้องมีไฟล์เสียง)
- **บทเรียน A1–C2** — ระดับละ 7 บท (รวม 42 บท): ไวยากรณ์หลัก 2 บท, **ภาษาอังกฤษในที่ทำงาน** 3 บท, การเดินทาง 1 บท และชีวิตประจำวัน 1 บท ทุกบทมีเป้าหมาย can-do, คำศัพท์พร้อมคำแปลไทย, ไวยากรณ์ (อธิบายไทย/อังกฤษ), บทอ่าน และแบบฝึกหัด 8 ข้อพร้อมเฉลย (มีข้ออ่านและข้อฟังทุกบท)
- **คลังคำศัพท์ & แฟลชการ์ด** — คำศัพท์ 210 คำจากทุกบท กรองตามระดับ ฟังเสียงได้ คำที่ยังไม่แม่นจะวนกลับมาก่อน ตอบ "จำได้" 3 ครั้งถือว่าจำได้แล้ว
- **เตรียมสอบ** — 13 ชุด: IELTS (Reading: True/False/Not Given, Matching Headings · Listening: Section 1–2, Section 3 · Writing Task 1, Task 2 · Speaking) และ TOEIC (Part 2, 3, 4, 5, 6, 7) พร้อมตารางเทียบ CEFR ↔ IELTS ↔ TOEIC
- **ความก้าวหน้า** — เปรียบเทียบผลก่อน–หลังเรียน รายทักษะ และจำนวนบทที่ฝึกแล้ว
- **บัญชีผู้ใช้ (แบบ CondoHub)** — ต้องเข้าสู่ระบบก่อนใช้งาน ผู้เรียนสมัครเองได้ ความก้าวหน้าบันทึกขึ้นเซิร์ฟเวอร์ (Google Apps Script + Google Sheets) จึงเรียนต่อได้ทุกเครื่อง
  - รหัสผ่านเก็บแบบ `sha256$<salt>$<hash>`, token ฝั่งเซิร์ฟเวอร์อายุ 30 วัน, ใส่รหัสผิด 5 ครั้งล็อก 15 นาที
  - **บัญชีแรกที่สมัคร = เจ้าของระบบ** เห็นเมนู "ผู้ดูแล": ผลก่อน–หลังเรียน บทที่ผ่าน คำศัพท์ที่จำได้ของผู้เรียนทุกคน ปิด/เปิดบัญชี และตั้งรหัสผ่านใหม่ให้
  - บันทึกแบบรวมข้อมูล (merge) ไม่ทับกัน ถ้าใช้หลายเครื่องพร้อมกัน ; ถ้ายังไม่ได้ตั้ง `VITE_API_URL` หน้าเข้าสู่ระบบจะมีแค่ "โหมดทดลอง" (เก็บในเบราว์เซอร์)

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm test         # ทดสอบทั้งหมด (รวมเซิร์ฟเวอร์ด้วยตัวจำลอง Google)
npm run build    # สร้างไฟล์ใน dist/
```

## ตั้งค่าเซิร์ฟเวอร์บัญชีผู้ใช้ (ครั้งเดียว)

1. เปิด https://script.google.com → **New project** → ลบโค้ดเดิม แล้ววางเนื้อหา `apps-script/Code.gs` ทั้งไฟล์ → บันทึก
2. **Deploy → New deployment** → ประเภท **Web app** → Execute as: **Me** · Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์ (Google จะขึ้นคำเตือน "unverified app" ให้กด Advanced → Go to … เพราะเป็นสคริปต์ของเราเอง)
3. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
4. Vercel → โปรเจกต์ English Hub → **Settings → Environment Variables** → เพิ่ม `VITE_API_URL` = URL ข้อ 3 → **Redeploy**
5. เปิดเว็บแล้ว **สมัครบัญชีของเจ้าของเป็นคนแรก**

ชีตข้อมูล "English Hub – ข้อมูลผู้เรียน" ถูกสร้างใน Google Drive ของเจ้าของโดยอัตโนมัติ (รัน `setup()` ในหน้า Apps Script เพื่อดูลิงก์ชีตใน Log)
แก้ `Code.gs` ภายหลัง: วางโค้ดใหม่ → **Deploy → Manage deployments → ✏️ → Version: New version** (URL เดิม)

> repo นี้เป็น Public — URL ของเซิร์ฟเวอร์จึงเก็บใน Vercel ไม่ได้อยู่ในโค้ด ; ในชีตมีชื่อผู้ใช้/ชื่อที่แสดง/ผลการเรียนเท่านั้น (ไม่มีอีเมลหรือข้อมูลส่วนตัวอื่น) และไม่มีรหัสผ่านจริง

## Deploy

เว็บ deploy ด้วย **Vercel** ซึ่งเชื่อมกับ repo นี้ไว้ จะ build และอัปเดตเว็บเองทุกครั้งที่ push (Framework: Vite, Build: `npm run build`, Output: `dist`)

GitHub Actions (`.github/workflows/ci.yml`) รันเทสต์และ build ทุกครั้งที่ push เพื่อตรวจว่าโค้ดไม่พัง

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/data/placement.ts` | คลังข้อสอบวัดระดับ และการสุ่มชุดข้อสอบ (`drawForm`) |
| `src/data/courses.ts` | บทเรียนหลัก A1–C2 |
| `src/data/courses-work.ts` | บทเรียนภาษาอังกฤษในที่ทำงาน |
| `src/data/courses-life.ts` | บทเรียนการเดินทางและชีวิตประจำวัน |
| `src/data/unit-extras.ts` | บทอ่านและแบบฝึกหัดเพิ่มเติมของบทเดิม |
| `src/data/exams.ts`, `exams-more.ts` | ชุดฝึก IELTS / TOEIC |
| `src/lib/flashcards.ts` | ชุดแฟลชการ์ดและลำดับการทบทวน |
| `src/data/levels.ts` | คำอธิบายระดับ CEFR และค่าเทียบคะแนนสอบ |
| `src/lib/scoring.ts` | การให้คะแนนและจัดระดับ |
| `src/lib/i18n.ts` | ข้อความหน้าเว็บภาษาไทย/อังกฤษ |
| `apps-script/Code.gs` | เซิร์ฟเวอร์บัญชีผู้ใช้และความก้าวหน้า (Google Apps Script) |
| `src/lib/auth.tsx`, `api.ts`, `store.tsx` | เข้าสู่ระบบ, เรียกเซิร์ฟเวอร์, บันทึกความก้าวหน้าอัตโนมัติ |
| `src/lib/merge.ts` | รวมความก้าวหน้า — **ต้องตรงกับ `mergeProgress_` ใน Code.gs** (`tests/parity.test.ts` ตรวจ) |
| `tests/` | ทดสอบเซิร์ฟเวอร์ด้วยตัวจำลอง Google (ไม่ใช้ Google จริง) |

การเพิ่มข้อสอบ: เขียนด้วย `q(id, skill, prompt, [คำตอบที่ถูก, ตัวลวง...])` โดยใส่คำตอบที่ถูกไว้ตัวแรกเสมอ ระบบจะสลับตำแหน่งตัวเลือกให้เอง

> หมายเหตุ: ค่าเทียบ IELTS/TOEIC เป็นค่าประมาณเพื่อแนะแนว ไม่ใช่คะแนนสอบอย่างเป็นทางการ
