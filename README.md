# English Hub

เว็บเรียนภาษาอังกฤษตามกรอบมาตรฐานสากล **CEFR (A1–C2)** สำหรับผู้ใหญ่/คนทำงาน พร้อม **ทดสอบวัดระดับก่อนและหลังเรียน** และส่วน **เตรียมสอบ IELTS / TOEIC** หน้าเว็บสลับภาษาไทย/อังกฤษได้

## ฟีเจอร์

- **ทดสอบก่อนเรียน (pre-test) / หลังเรียน (post-test)** — 6 ระดับ ระดับละ 6 ข้อ (ไวยากรณ์ คำศัพท์ การอ่าน การฟัง) ข้อสอบก่อน–หลังเป็นชุดคู่ขนาน (คนละข้อ ความยากเท่ากัน) และจะหยุดเองเมื่อถึงระดับที่ยากเกินไป
  - ผ่านระดับเมื่อถูก ≥ 4/6 ข้อ และต้องผ่านทุกระดับก่อนหน้า (`src/lib/scoring.ts`)
  - ข้อฟังใช้ Web Speech API ของเบราว์เซอร์ (ไม่ต้องมีไฟล์เสียง)
- **บทเรียน A1–C2** — แต่ละบทมีเป้าหมาย can-do, คำศัพท์พร้อมคำแปลไทย, ไวยากรณ์ (อธิบายไทย/อังกฤษ), บทอ่าน และแบบฝึกหัดพร้อมเฉลย
- **เตรียมสอบ** — IELTS Reading/Listening/Writing/Speaking และ TOEIC Part 2/5/7 พร้อมตารางเทียบ CEFR ↔ IELTS ↔ TOEIC
- **ความก้าวหน้า** — เปรียบเทียบผลก่อน–หลังเรียน รายทักษะ และจำนวนบทที่ฝึกแล้ว
- ไม่มีเซิร์ฟเวอร์: เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm test         # ทดสอบระบบให้คะแนน
npm run build    # สร้างไฟล์ใน dist/ (deploy บน GitHub Pages, Vercel, Netlify ได้ทันที)
```

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/data/placement.ts` | ข้อสอบวัดระดับ ชุด A (ก่อนเรียน) และชุด B (หลังเรียน) |
| `src/data/courses.ts` | บทเรียน A1–C2 |
| `src/data/exams.ts` | ชุดฝึก IELTS / TOEIC |
| `src/data/levels.ts` | คำอธิบายระดับ CEFR และค่าเทียบคะแนนสอบ |
| `src/lib/scoring.ts` | การให้คะแนนและจัดระดับ |
| `src/lib/i18n.ts` | ข้อความหน้าเว็บภาษาไทย/อังกฤษ |

การเพิ่มข้อสอบ: เขียนด้วย `q(id, skill, prompt, [คำตอบที่ถูก, ตัวลวง...])` โดยใส่คำตอบที่ถูกไว้ตัวแรกเสมอ ระบบจะสลับตำแหน่งตัวเลือกให้เอง

> หมายเหตุ: ค่าเทียบ IELTS/TOEIC เป็นค่าประมาณเพื่อแนะแนว ไม่ใช่คะแนนสอบอย่างเป็นทางการ
